# Prep Simulator for CSCA

A free Android app by [HomiLabs](https://homilabs.org) for international students preparing for the CSCA (China Scholastic Competency Assessment), the undergraduate admission test for Chinese universities: 20 full-length timed mocks each for Mathematics, Physics and Chemistry, study notes and practice for every topic, and a guide to registration, test day and exam tactics. Independent practice material, not affiliated with the China Scholarship Council.

- App: Flutter, in `lib/`. Project notes: `CLAUDE.md`.
- Question bank: `content/bank/`, built into `assets/data/` by `tool/build_content.py`.
- Website: `website/`, live at https://csca.homilabs.org.
- Release and hosting: `docs/release-and-hosting.md`.
